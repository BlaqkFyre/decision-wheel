# Decision Wheel

A single-file app (`index.html`) that shows evangelical and end-times beliefs as a radial wheel, and compares them with theologians, authors and survey users.

- Open `index.html` in a browser to use it.
- Answers are built into the file; in Chrome or Edge, Survey → **Link this file** saves changes straight back into `index.html`.
